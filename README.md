# IoT Health Monitor

Machine learning based preeclampsia risk prediction system using IoT sensors and Flask.

## Features
- Predicts preeclampsia risk
- Uses machine learning model
- Flask-based web application
- Sensor data monitoring
- CSV dataset integration

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- IoT Sensors

## Project Structure
```bash
app.py
preeclampsia.csv
README.md
```

## How to Run

1. Install required libraries

```bash
pip install flask pandas scikit-learn pyserial
```

2. Run the application

```bash
python app.py
```

3. Open in browser

```bash
http://127.0.0.1:5000
```

## Dataset
The project uses a preeclampsia dataset for training and prediction.
